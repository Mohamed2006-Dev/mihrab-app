# اعتماد HadeethEnc وروابط المصدر

المصدر الوحيد للأحاديث والشروح هو موسوعة الأحاديث النبوية HadeethEnc.com.

أضيف رابط مباشر منسق بألوان القالب إلى صفحة كل حديث في البطاقة الرئيسية، وأسفل الشرح، وبطاقات المكتبة. يظهر اسم الناشر والمصدر بوضوح. تتضمن الروابط أيقونات SVG وحالة تركيز بلوحة المفاتيح وألواناً مناسبة للوضعين الليلي والنهاري، دون ألوان الروابط الافتراضية الزرقاء.

تفتح الروابط في المتصفح الافتراضي. يطلب التطبيق فتح المصدر بواسطة معرّف الحديث المخزن؛ يشتق الجزء الرئيسي الرابط الرسمي ولا يقبل عنواناً عشوائياً من الواجهة. يدعم النقر المعتاد ولوحة المفاتيح والنقر الأوسط. لا توجد روابط داخل أزرار متداخلة.

أضيف اسم الناشر ورابط الحديث إلى النص المنسوخ والصورة المصدرة أيضاً. يبقى المتن والشرح كما حفظهما المصدر؛ معاينات المكتبة تستخدم قصاً بصرياً بالأنماط دون تغيير النص الأصلي في السجل أو في العرض الكامل.

التحقق: نجاح 80 اختباراً عاماً، وفحص الواجهة في نافذة معزولة دون إنترنت. تحقق الفحص من رابط الحديث الصحيح ومسار الفتح، وروابط البطاقات الـ24، والعزو، وعدم استخدام الأزرق الافتراضي، ومطابقة نص العرض للسجل، وعدم وجود حقل مفتاح API في الإعدادات.

الملفات المحدثة: src/ui/index.html وsrc/ui/renderer.js وsrc/ui/style.css وsrc/engines/hadith-engine.js وsrc/engines/hadith-image.js وmain.js وpreload.js وtest-hadeethenc.js.

للتجربة أغلق التطبيق بالكامل وشغّل npm start. لم يتم بناء ملف تنفيذي جديد.
