# تحميل صورة الحديث

زر «تحميل صورة» في تبويب حديث اليوم والصلوات يحفظ PNG يتضمن المتن والراوي والمحدّث والمصدر ودرجة الحديث. تبرز الدرجة في شريط مستقل. تظهر عبارة صريحة عندما لا يذكر المصدر معلومة أساسية، ولا يضع المولد درجة افتراضية. رقم الصفحة اختياري ويظهر عند توفره.

المولد `src/engines/hadith-image.js` يرسم بطاقة بعرض 1200 بكسل وارتفاع يتكيف مع النص، بخط عربي محلي وزخارف هندسية خفيفة وألوان زمردية وورقية. يعمل دون صور أو خطوط أو خدمات خارجية. لا يُقص النص الطويل؛ يتوقف بخطأ واضح إذا تجاوزت البطاقة الحد الأقصى.

يدعم أيضاً الاستخدام المستقل من جذر المشروع:

```powershell
npm run export:hadith-image -- --key seed_006 --output "C:\Users\MSI\Pictures\hadith.png"
```

احذف `--key` لتصدير الحديث المختار حالياً. لقاعدة مستخدم أخرى، مرّر `--data-dir "مسار مجلد data"`. السكريبت المستقل `scripts/export-hadith-image.cjs` يقرأ البيانات فقط ولا يشغّل التطبيق الأساسي أو يعدّل المكتبة. يجب أن يكون مجلد الوجهة موجوداً، والملف بامتداد `.png`.

تُهَرَّب النصوص قبل إدراجها في التصميم، ويعمل الرسم في نافذة مخفية معزولة تُغلق بعد الحفظ أو الخطأ. إلغاء نافذة اختيار الملف لا ينشئ صورة ولا نافذة رسم. لم يتطلب التحديث أي بناء أو تجميع.
